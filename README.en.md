# One-Click Pronunciation – Anki Add-on

🇩🇪 [Deutsche Version](README.md)

> **About this project:** This is my first vibe-coding project. I'm using it to learn
> what AI coding assistants can do and to keep up with the times. Most of the code was
> generated by AI under my direction.

While adding or editing a card, one click inserts a **pronunciation audio file** for the
foreign word or sentence, in the language and **accent** you choose (for example British or
American English). The audio is placed in a field on the **back** of the card, so it only
plays after you reveal the card or answer the cloze.

> The user interface is available in **English and German** and follows Anki's language
> automatically (configurable via `"language"` in the add-on config).

## Installation

**Easiest – download the ready-made file:**
1. On GitHub, open the latest version under **Releases** and download
   `pronunciation_tts.ankiaddon`.
2. Double-click the file and Anki installs it. (Or in Anki: *Tools → Add-ons →
   Install from file…* and pick the file.)
3. Restart Anki.

**Build it yourself** (e.g. for the latest state; only Python needed):
- Windows: double-click `build.py`.
- macOS / Linux: run `python3 build.py` in the project folder.

The file ends up in `dist/pronunciation_tts.ankiaddon`.

(Alternatively, copy the `pronunciation_tts` folder into Anki's add-on folder:
*Tools → Add-ons → View Files*.)

## Usage
Two speaker buttons appear in the editor:

| Button | Shortcut | Action |
|---|---|---|
| 🔊 | `Ctrl+Alt+P` | Insert pronunciation right away (using the remembered settings) |
| 🔊⚙ | `Ctrl+Alt+Shift+P` | Choose fields, language/accent and service |

The first time you use it for a note type, a dialog opens; your choices are then remembered for that note type:
- **Read text from field**: the field holding the foreign word or sentence (e.g. "Back"; for clozes "Text", where the whole sentence is read, answers included).
- **Insert audio into field**: a field that is shown **only on the back** (e.g. "Back", "Back Extra" or your own "Audio" field). Front-side fields are refused so the audio can't give the answer away.
- **Insert audio** (cloze note types only): into a back-side field or directly into the cloze (see below).
- **Language / accent**: e.g. English (British / American / Australian / Indian …), French (France / Canada), Spanish (Spain / Mexico), Portuguese (Brazil / Portugal) and many more.

### Audio directly inside the cloze
For cloze notes, choose **"Directly into the cloze"** under "Insert audio". Then

    Stop being so {{c1::petty::kleinlich}}.

automatically becomes

    Stop being so {{c1::petty [sound:pron_en-GB_….mp3]::kleinlich}}.

You don't need an extra field. The cloze is hidden on the front, so you only hear the audio
after revealing it. Under **"Read aloud"** you choose:
- **Whole sentence**: "Stop being so petty."
- **Cloze word only**: "petty" (each cloze gets its own audio)

Caveat: if a note has several cloze *numbers* (`c1`, `c2` …), the card for c1 shows c2 as
plain text, so c2's audio would already play on the front. The add-on asks before inserting
in that case. For such notes, a back-side field like "Back Extra" is the better choice.
Several clozes with the *same* number (`{{c1::…}} … {{c1::…}}`) are fine.

Tip for "Basic (and reversed card)": both fields appear on a front side. Add an extra field
`Audio` and put `{{Audio}}` only on the back template of the card you want.

Anki plays back-side audio automatically unless "Don't play audio automatically" is
enabled in the deck options.

## Where are the audio files stored?
In your Anki collection's regular **media folder** (`collection.media`), next to the images
and other audio of your cards:

| System | Folder |
|---|---|
| Windows | `%APPDATA%\Anki2\<profile name>\collection.media` |
| macOS | `~/Library/Application Support/Anki2/<profile name>/collection.media` |
| Linux | `~/.local/share/Anki2/<profile name>/collection.media` |

`<profile name>` is usually `User 1`. In Anki you can open the profile folder via
*File → Switch Profile → Open Profile Folder*; `collection.media` is inside it.

- Files are named `pron_<language>_<id>.mp3`, e.g. `pron_en-GB_3f9c….mp3`.
- Like all media they are **synced via AnkiWeb**, so they are also available on your phone (AnkiDroid / AnkiMobile).
- If a card is deleted or its audio replaced, the old file stays at first. *Tools → Check Media* lists unused files and can delete them.

## Services
- **Google Translate** (default): free, no key. The accent is selected through the regional Google domain (`translate.google.co.uk` = British, `.com` = American …). This is an unofficial interface and may change.
- **Google Cloud Text-to-Speech**: the official API with high-quality voices per dialect. Enter your API key under *Tools → Add-ons → Config* and set `"provider": "google_cloud"`.

## Security
All downloads go through a hardened HTTPS client:
HTTPS only with certificate and hostname verification (TLS ≥ 1.2), a fixed list of allowed
hosts, no redirects, time and size limits, a check that the response really is an MP3 file,
locally generated file names, and API keys sent only in an HTTP header.
The same text is not downloaded twice (cached via a hash in the file name).
